# Stage 1.7 事前登録（本実験の前に固定。2026-10-18）

**確認的**（一次仮説P1〜P6と、操作の確認M1〜M5）と**事後**（結果を見てから行う分析）を分ける。事後分析は結論に使わない。

本実験の前に行ったのは、(1) エンジンの回帰確認（Stage 1.6と84通りでビット一致）、(2) 食料補助の較正（下記、シード901〜910。どの検定にも使わない）、(3) スクリプトの動作確認（少数シード・短い期間）だけ。介入の効果は見ていない。

## 問い
「短期の繁殖 → 捕食 → 獲物の枯渇 → 系統の絶滅」という因果の連鎖を、**食料補助なしで**検証する。Stage 1.6の「獲物の避難」は、獲物を守ると同時に、毎ステップ獲物を補充する食料補助でもあった。

## 較正：Stage 1.6の避難が供給していた食料（シード901〜910、パルス供給、選択あり）
- 避難（下限30%）が毎ステップ補充した獲物：**容量の0.194倍／区画（パッチ）・ステップ**（約7.8頭/区画/ステップ）。
- 獲物の自然な産出：0.065／区画・ステップ。捕獲された獲物：0.260。つまり**避難は、捕獲された獲物の約75%を補っていた**。
- この値（0.194）を「食料補助のみ」の介入の流入量に使う。

## 一次仮説（片側。方向は「介入が絶滅を減らす／増やす」）
評価項目：絶滅した試行の割合（同じシードの基準との対応比較）。個体数・個体寿命・系統存続期間は**別の指標として**併記し、絶滅の判定には使わない。
| ID | 仮説 | 比較 |
|---|---|---|
| P1 | 保護のみ（容量の30%を保護）で、絶滅が減る | 基準 − `hidden30` |
| P2 | 食料のみ（流入0.194）で、絶滅が減る | 基準 − `inflow194` |
| P3 | 出生数を半分にすると、絶滅が減る | 基準 − `birth0.5` |
| P4 | 出生数を2倍にすると、絶滅が増える | `birth2` − 基準 |
| P5 | 狩りの成功率を半分にすると、絶滅が減る | 基準 − `capture0.5` |
| P6 | 獲物の成長率を3倍にすると、絶滅が減る | 基準 − `growth3` |

## 判定規則
各一次仮説の「支持」は次を**すべて**満たすこと：
1. Holm補正（6仮説）後の片側 p < 0.05（絶滅割合の差に対する厳密な片側McNemar検定）
2. 絶滅割合の差のブートストラップ95%CIの下限 > 0
3. 独立シード101〜130で、同じ方向かつ片側 p < 0.05（補正なし）
4. 対応する操作の確認（P1：M4、P2：M5、P3とP4：M1、P5：M2、P6：M3）に合格

### 因果の主張に関する規則（事前に固定）
- **「短期の繁殖は絶滅の原因である」**は、P3とP4の**両方**が支持され、M1に合格し、さらに繁殖を動かしたときに獲物の割合（初期）が期待の向きに動いたとき**だけ**認める。そうでなければ**未証明**と記録する。
- **「獲物の避難の効果は、保護によるか、食料補助によるか」**：P1とP2の支持／不支持の組み合わせをそのまま記録する。
- 陽性対照（`refuge_floor`）が絶滅を減らさなければ、実験の感度に問題があるとして、結論を保留する。
