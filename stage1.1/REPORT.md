# Stage 1.1 技術レポート（2026-10-17）

条件：各条件30シード、学習2000ステップ、アッセイ600ステップ、創始個体100。統計は平均・Cohen's d・Mann-Whitney U（両側）、絶滅数はFisher正確検定。実測環境はNode 22（サンドボックス）。Pixel 7a実機は未計測。

## 結論
ゲート5条件のうち **4つ達成、1つ部分達成**。ただし「遺伝子制御相互作用が有利に働く」「別環境への汎化が選択特有」は **未達**。

## 達成したこと（実測）
| ゲート条件 | 結果 |
|---|---|
| 生存は保証されない | 限界環境(brink・変動)で **17/30 絶滅**。同環境・固定では0/30。豊かな環境→1000ステップ目にbrinkへ急変で **10/30 絶滅**（急変なし0/30, p=0.0008） |
| 環境摂動で結果が変わる | 上記急変で最終個体数 514→20。変動/固定でbrink絶滅 17 vs 0（p=6×10⁻⁷） |
| 選択とドリフトを区別 | 学習環境アッセイの平均個体数：選択 327 vs ドリフト 256 vs 祖先 245（選択vsドリフト d=6.2, p=3×10⁻¹¹）。形質の祖先からの移動量 0.72 vs 0.08（d=14）。brinkでの絶滅：選択17/30 vs ドリフト28/30（p=0.002） |
| ホールドアウト環境 | 寒冷・疫病（学習に未使用）でも選択系統 > ドリフト（d=4.8 / 6.0）。※ただし下の未達参照 |

## 未達・弱い点（正直に）
1. **制御相互作用は不利**：相互作用ONの方がOFFよりアッセイ個体数が低い（327 vs 338, d=−1.1）。制御辺は平均1.3本と少なく、可塑的な発現制御（例：病原体信号→免疫上昇）は進化していない。仕組みはある（テストで確認）が、コストに見合う利益を生む条件になっていない。
2. **限界環境への汎化は選択特有でない**：brinkアッセイでは選択系統もドリフト系統も祖先より同程度にわずかに良い（38.8 / 37.3 / 35.5）。
3. **寿命・修復の差は選択特有と言えない**：外因死亡による内在寿命の差（61 vs 54）はドリフト対照でも同方向に出る（129 vs 100）。選択特有と確認できたのは繁殖発現だけ。
4. **変動環境で鍛えた系統が汎化に強い証拠なし**：学習・寒冷・疫病では固定環境系統の方が同等以上。brinkのみ変動系統が優勢だが有意でない（p=0.07）。
5. ドリフト対照も祖先よりわずかに高性能（d≈1.4）。変異の偏り（発現が下がる方向＝コスト減）による。対照として完全に中立ではない。
6. 選択は「維持コストを下げて個体数を増やす」方向に強く働き、ゲームの目標である「極少数個体で超長期生存」とは逆向き。目標に沿う選択圧の設計は未着手。

## 限界
- 5つの固定チャネル以外の能力・器官は生まれない。創発を主張しない。
- 無性生殖のみ（単一系統）。組換え・水平伝播・休眠からの再出現の系統的検証なし。
- 全パラメータは手調整の仮定値。生物学的妥当性は未検証。
- Pixel 7a実機速度・中断/再開・オフライン進行は未計測。
