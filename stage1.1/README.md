# オメガ・コドン Stage 1.1 進化エンジン

個体ベースの抽象進化モデル。UIから分離した依存ゼロの単一ファイル `engine.js`（Node / Chrome 両対応）。
**実在生物の予測ではなく、新器官や本物の生物学的創発も生まない**（後述「限界」）。

## ファイル
| ファイル | 内容 |
|---|---|
| `engine.js` | エンジン本体。`simulate(options)` / `assay(genomes, options)` |
| `test.js` | 自動テスト14件（`node test.js`） |
| `experiments.js` | 30シード比較・アブレーション・ホールドアウト（`node experiments.js`） |
| `results.json` | 上記の実測結果（2026-10-17生成） |
| `REPORT.md` | 日本語技術レポート（達成/未達を分離） |
| `index.html` | 最小限のブラウザ試験画面 |
| `stage1-original/`, `AUDIT.md`, `CLAUDE_HANDOFF.md` | 受領したStage 1一式（参照用・無変更） |

## 再現手順
```
node test.js                       # 約8秒、ALL PASS (14)
node experiments.js --seeds 30     # 約135秒、results.json を出力
```
ブラウザ：`index.html` を開いて「実行」。乱数は mulberry32、同一オプションなら完全に同一結果。

## モデル概要（すべて抽象化）
- **1ステップ＝1季節**。個体は年齢・エネルギー・損傷・病原体負荷を持つ。
- **個体数は強制しない**。出生（成熟3ステップ以降、エネルギー余剰と繁殖発現に依存）と死亡（外因死＋損傷²＋飢餓）だけで決まり、絶滅し得る。安全上限6000は超過時 `capHit=true` を報告（通常条件では未到達をテストで確認）。
- **資源**：4パッチ。パッチ生産量を需要比で分配し、さらに餌の疎らさで上限がかかる（貧しい環境は密度に関係なく生存不能になり得る）。
- **損傷**：年齢とともに増える老化＋温度ストレス＋感染＋災害。修復発現で除去（飢餓時は効率低下）。
- **病原体**：背景圧＋パッチ内感染率による伝播。免疫で感染確率低下・負荷除去。
- **環境**：固定／変動。変動時はパッチごとに確率0.01で条件が切替わり、確率0.004で局所災害（損傷＋15ステップの飢饉）。`shift` で意図的な環境急変。
- **遺伝子**：順序付きブロック列（機能チャネル・強度・発現ON/OFF）。位置が後ろほど効果減衰（順序が意味を持つ）。変異：強度変化・チャネル置換・重複・欠損・転座・逆位・サイレンシング/再活性化。
- **制御関係**：変異可能な制御辺（信号5種＋チャネル5種 → チャネル、重み±4）。辺の追加・削除・重み変更。発現＝遺伝子量×制御倍率(0〜2)。
- **トレードオフ**：発現量・遺伝子数・制御辺数がそれぞれ維持コスト（エネルギー）。繁殖はエネルギー0.55を消費。
- **選択なし対照**：遺伝型は継承・変異するが発現しない（全個体が祖先の表現型で生きる）→ 遺伝型は純粋なドリフト。
- **アッセイ（共通圃場）**：進化後のゲノム100個体を変異なしで別環境に置き600ステップ測定。

チャネル：forage（採餌）/ repair（修復）/ immune（免疫）/ tolerance（耐性）/ fecundity（繁殖）。この5つ以外の能力は存在しない。

## 主要パラメータ（仮定）
`engine.js` 冒頭の `DEFAULTS`・`ENVIRONMENTS` と定数群に全て記載。値は「絶滅が起こり得て、かつ通常環境では数百個体で安定する」ように手で調整したもので、実在生物から推定した値ではない。
