# Stage 1.9A — 時間表示・生息域マップ・自動イベント・競争相手

Stage 1.8（プレイ可能版）の上に積んだ変更。進化エンジンは Stage 1.7 と同じ（`test19.js` が通常実行・ライブ実行ともにビット単位の一致を検証）。

- `game.js` 注目系統／競争相手、自動イベント、単調な世代・時間の推定、セーブv2（v1も読み込み可）。
- `timemodel.js` ステップ→日・年の換算。校正されていない**仮定**であることを表示。

- 変更しないもの：自然選択エンジン。勝利判定は未実装で、将来もエンジンとは分離する。
