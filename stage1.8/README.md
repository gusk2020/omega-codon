# Stage 1.8 — Omega Codon プレイ可能な試作版

`index.html` を開くだけで遊べます（ビルド不要・外部ライブラリなし）。進化エンジンは Stage 1.7 のもの（`engine18.js` は `engine17.js` を「一歩ずつ進められる」ようにしただけで、非ライブ実行はStage 1.7とビット単位で一致。`test18.js` で確認）。

- `game.js` ゲーム層（生き物の選択、出来事の検出、分岐点の介入、セーブの再現）。科学モデルは含まない。
- `app.js` / `style.css` / `index.html` スマホ向けの2D表示。
- セーブ：選択・乱数の種・介入の記録だけを保存し、読み込み時に同じ手順を再現する（決定論的なので同じ結果になる）。ブラウザの localStorage に保存。
- 介入は分岐点でだけ（見守る／食料支援／保護区／災害）。どれも全系統に平等で、特定の形質や系統を直接有利にしない。
