# Stage 1.9B — 4つの領域・地球史の開始点・ダミーの適応範囲

Stage 1.9A（PR #5）の上に積んだ変更。領域を使わない通常実行は Stage 1.7 とビット単位で一致（`test19b.js`）。

- `engine19.js` 領域（`realms`オプション）を追加。既定は無効で、旧セーブは従来どおりの動き。
- `earthhistory.js` 約6,604万年前（K–Pg）のシナリオ、年表、衝突後の外部条件（ゲーム上の仮定）。
- `adaptation.js` **ダミー**の適応範囲（進化計算とは未連動）。差し替え用の表示層。
- `game.js` 領域・シナリオの設定、領域別の集計。セーブはv3（v1・v2も読み込み可）。
- `docs/`（Private専用）設計台帳と地球史の参照情報。
