# オメガ・コドン Stage 1.3

遺伝子ブロック方式の遺伝子制御ネットワーク（GRN）で形質を発生させる個体ベース進化エンジン。行動モード・長寿戦略・細胞記憶はStage 1.2から継承。依存ゼロで、Node と Chrome の両方で動く。
抽象モデルであり、実在生物の予測ではない。結果と未達は `REPORT.md` を参照。

## モデルの要点（Stage 1.3の追加は REPORT.md §2）
- **個体**：暦年齢、内部時間、能動時間、エネルギー、損傷、病原体負荷、元細胞割合O、記憶M（M≤O）、交換による幹細胞疲弊P、行動モード。
- **行動**：休眠・待機・探索・狩猟・修復の5モード。
  - 入力は10種：定数、獲物の手がかり、資源の不足、温度、災害直後、エネルギー、損傷、感染、生体リズム(sin/cos)。
  - これを変異可能な制御回路（辺の追加・削除・重み変更）で重み付けして選ぶ。
  - 切替には閾値・エネルギーコスト・移行の1ステップを要する。休眠からの覚醒は深さに応じて遅れる。
- **感知**：獲物の手がかりに、進化する偽陽性率・偽陰性率がある。記憶があると誤りが減る。
- **再生**：修復（元細胞を保つ、高コスト）と交換（安く速い、元細胞と記憶を失う、繰り返すと効率が落ちる）。
- **変異する遺伝子座**：代謝、移動、捕食、耐性、免疫、繁殖、修復率、交換比率、休眠の深さ、偽陽性、偽陰性、記憶の獲得、記憶の維持、切替閾値、リズムの周期と位相。
  - 単一の「長寿能力値」はない。
- **Stage 1.1から引き継いだ仕組み**：出生・死亡・病原体・局所災害・環境の切替・個体数を固定しないこと・安全上限の報告。
