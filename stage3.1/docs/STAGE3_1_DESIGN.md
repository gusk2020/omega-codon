# Stage 3.1 設計記録（非公開）

## 方針
情報量を減らし（通常画面は「時代・危険・ランクの不足・系統・方針・直近の出来事」だけ）、介入を「環境」から「他者への行動方針」へ変え、進化の経路と出来事を増やした。Stage 3.0のモデルは削除していない（`cfg.stage===3.1` の世界だけが新しい経路を通る。旧セーブ v5〜v7 は従来経路のまま同じ結果に再生される）。依存：PR #11（Stage 3.0）の上に積んだ別Draft PR。

## 区分
- **実在する現象（に基づく）**：突然変異（点・重複・欠失・転座・逆位・サイレンシング）、水平伝播（微生物で一般的、動物ではまれ）、内部共生（ミトコンドリア等）。
- **ゲーム上の仮定**：頻度（交換 0.0004、融合 0.0003、分離 0.02＝いずれも個体・ステップあたり）、感染中の水平伝播を4倍にすること、動物でも起こり得るという拡張、融合の成立条件（捕食力×(1−0.6×免疫)）、分離が飢えで2倍になること、方針ごとの効果量、環境支配力の重みと基準値。科学的に実証済みとは言わない。
- **実計算**：交換・融合で実際に遺伝子が増え（発生後に再発達）、形質→箱→損傷→生存に反映。融合の相手は実際に死ぬ（エネルギー収支は閉じる：テストで確認）。
- **未計算**：他種への依存関係（環境支配力）、宇宙での自律生存、箱の中心の進化。

## 1. 介入の廃止
旧「分岐点」の選択（食料支援・保護区・災害）は 3.1 では出さない。分岐点は注記イベントに変わり、一時停止も選択肢もない（`game.pending` は常に null、`choose()` は false）。ログに環境操作は入らない。3.0 以前のセーブの `choice` ログは従来どおり再生される。

## 2. 方針（3対象）
文明（敵対／共存／回避／防御＝既存の方針）、植物・固着生物（捕食・利用／共生／回避／競争）、他の動物（捕食・敵対／共存／回避／防御）。系統ごとに別々に保存し、操作中の系統だけを変える。植物・動物は生物学的分類ではなく生活様式で分けた（菌類・固着動物も「植物など」）。方針は体の能力で成否が決まる（能力 0.3 未満は失敗：使う→摂取0.9倍、捕食・敵対→成功率0.85倍）。代償：利用＝資源を食い荒らす／共生＝摂取0.88倍／競争＝警戒の費用／防御＝警戒の費用。測定（短期・同じ乱数）：植物の利用 +62%、回避 −65%、能力不足の利用 −14%。

## 3. 環境支配力
`0.35×利用（1個体のステップあたり摂取）＋0.15×影響（1個体あたり捕獲）＋0.25×持続（直近の寿命）＋0.25×広さ`。個体数は式に入らない（テストで式をそのまま検算、ソースに頭数が現れないことも検査）。5体未満は「参考」。Ω評価・生存可能性・個体数とは別。実測：同条件で個体数の多い系統より少ない系統の支配力が大きい世界がある（テストで確認）。

## 4. 進化の経路の自由化
参考の道筋（点線）と進化の境界を分離。エンジンは領域間の移動を全組み合わせで許し、参考ルート以外は難度（水中↔空中 3.0、地中↔空中 2.5）と受け入れ確率（0.15）で高コスト。実測（2500ステップ）：参考ルート外の移動は参考ルートの約1/15〜1/20で、薄い空に住む数は地上より多くならない。「異端」は発見として記録するだけで、生存確率にもランクにも入らない（rank.js は発見・支配力・希少性を参照しないことをテストで検査）。

## 5. 進化の出来事
各出来事は 発生→定着（150ステップ後に3個体以上が受け継ぐ）→消失 を区別。追跡は目立つもの（新しい働き、形質の8%以上の変化、交換、融合、分離）で、回数はすべて数える。種類ごとに追跡枠を持つ（突然変異200、交換100、融合60、分離40）。12000ステップの1例：突然変異 約5万、交換 303、融合 5、分離 2（追跡中の定着 24／消失 278／途中 98）。

## テスト専用の近道
`v31.rates`（まれな出来事の頻度を上げる）、`testStartYears`、`testHooks`（3.0のもの）。通常のゲームでは使わない。

## 性能・保存
同じ6000ステップ：3.0 = 3504 ms、3.1 = 3750 ms（1.07倍）。セーブは3.1のほうが小さい（256 B 対 645 B：環境介入のログがないため）。ブラウザの×600でも画面の配置は変わらない（360/412 px で測定）。

## 既知の限界
- 系統の枠は創始者ごとに固定（4まで）。「分離」は同じ系統の中の子孫として追跡し、新しい系統の枠は作らない。
- 融合・交換の頻度は仮定であり、長期バランスは未検証。実機での確認も未了。
- 方針の効果量は最初の仮定のまま（結果を見て調整したのは動物の方針のみ：狩りの利得+25%、獲物を残す量0.75。最初の値では「捕食・敵対」が「方針なし」に負けたため）。
