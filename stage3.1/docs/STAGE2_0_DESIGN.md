# Stage 2.0 設計メモ（Private専用）

## 1. 何が「実計算」で、何が「仮定」か

| 項目 | 区分 | 内容 |
| --- | --- | --- |
| 個体の老化・損傷・修復・更新・休眠・免疫・順応・記憶 | 実計算（1.9Dまで） | 遺伝子→形質→個体の生存。費用あり（代謝・修復・免疫・記憶の維持）。 |
| 異常細胞（がん様） | 実計算（新・ゲーム上の式） | 発生は「細胞の入れ替え量×損傷×年齢」、修復で発生を抑え、免疫の監視で除去、大きくなると死因。免疫・修復には費用あり。入れ替えによる再生には「異常細胞が増える」という実コストが付く。 |
| 長寿型と繁殖型 | 実計算 | 長寿に隠れた補正はない。同じ餌では繁殖型が圧倒し、周期的な長い飢えでは長寿型が勝つ回がある（test20b）。 |
| 世代・個体の年齢 | 実計算 | 実際に計算したステップだけ進む。跳躍では進めない。 |
| 時間：1ステップ＝30日 | ゲーム上の仮定 | 最初の生き物の寿命（約25ステップ）を約2年とみなす。旧方式は1ステップ＝1日（未校正）。 |
| 跳躍（世界の時計だけを大きく進める） | ゲーム上の仮定＋統計的近似 | 気候・文明・天体衝突は粗い計算で進む。生物は進化しない。個体は記録された最長寿命を超える期間は生き延びず、同じ遺伝子の子孫に入れ替える。減り続けていた系統の減少は外挿して絶滅と判定（増加は外挿しない）。 |
| 跳躍の長さ | 実計算（誤差制御） | 文明・気候の変化量、出現と天体衝突の期待数が小さいよう自動で決める。文明の積分は刻みの二重化で誤差を抑え、1/8/64分割で収束を確認（test20b）。 |
| 長寿な個体の保護 | 実計算 | 400ステップ以上かつ系統の平均寿命の4倍を超える個体がいる間は跳躍しない。 |
| 太陽光度 | 科学的な標準近似 | L/L0 = 1/(1+0.4(1−t/t☉))。 |
| 気温への反映 | ゲーム上の仮定 | 感度0.8K/(W/m²)、風化による調整で78%が打ち消される。**約10億年後に全生命が絶えるとは決めていない。** |
| 天体衝突・大噴火の頻度 | 大まかな目安（ゲーム上の仮定） | 9千万年に1回、3千5百万年に1回。 |
| 文明 | ゲーム上の仮定（抽象モデル） | 5系統のどれでもない知性種。出現は「生物圏の認知能力（計算した系統の認知指標）・気候・資源・汚染・前の文明の遺産・前の文明からの経過」で決まる確率。周期なし。 |
| 文明の出現頻度 | ゲーム上の仮定（結果を見て調整） | 地球の実績より高く設定。下記の調整記録を参照。 |
| 文明の手段 | ゲーム上の仮定 | 技術段階で解禁：捕獲(1.5)・駆除(2.5)・資源の独占(3)・封じ込め(4)・生態系改変(5)・機械による攻撃(6)・惑星規模の改変(7.5)。予算・安定を消費。常に攻撃する万能の敵ではない。 |
| 4つの方針 | ゲーム上の仮定 | 逃避＝移動できる個体が安全な領域へ、防御＝耐性・免疫・修復で捕獲と損傷を減らす（警戒の費用）、攻撃＝捕食能力で文明にダメージ（反撃で自分も危険、高技術には効かない）、共存＝文明が「役に立ち脅威でない」と見なした系統だけ。 |
| U単位 | 表示 | アリーナの実個体10体＝1U、背景10単位＝1U。世界全体の個体数は作らない。 |
| ランク | 観察（計算に影響しない） | 7軸（老化・修復・効率・範囲・休眠・自力の生存・競争）。Ωは判定しない。 |
| 適応範囲の重ね描き | 仮表示（ダミー） | 進化計算とは無関係。 |
| 未実装 | — | 体細胞のゲノム変化、宇宙編、Ωの判定、敗北条件、温度・圧力範囲の実計算、社会的知性の個体への割り当て、文明と生物の共進化。 |

## 2. 結果を見てから変えたパラメーター（記録）

- 文明：出現率 1.3e-8→2.6e-8（10億年に約4回→約10回）、環境負荷の発生 0.25→0.12、突発の乱れ 0.5→0.2、安定の回復 0.35→0.5、崩壊の重なりの減衰 0.6→0.7、資源の消費 0.004→0.006。目標は「10億年に数回以上、続いた期間はおおむね10万年、崩壊を繰り返して滅びる」。**勝利条件や生物の能力は一切いじっていない。**
- 跳躍の準備：最初の跳躍は6000ステップ以降、窓は400ステップ以上、減少の外挿は「窓の最後の4分の1が最初の4分の1の半分未満」のときだけ。操作系統が最初の跳躍で絶えた試行を見て、外挿を厳しくした（絶滅が早すぎたため）。
- 文明の態度の閾値、手段ごとの強さ：予備の試走で各方針に差が出ることを確認して固定。

## 3. 既知の限界

- 圧力が捕獲だけの場合、出生で数が補われ、個体数ではなく寿命・回転率に現れる（生息地の改変は個体数を減らす）。
- 跳躍中に生物は進化しないので、「経過年」は進化の量を意味しない。
- 速度：端末とエンジンの都合で、最高の「×600」でも実測は毎秒2000ステップ前後。
- 地球の気候モデルは全球平均の単純な式だけ。
