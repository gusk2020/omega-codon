# 現行エンジンの調査（Stage 1.9D の開始時点）：個体の長寿命・修復・老化は、すでに何が計算されているか

結論：**個体としての老化・損傷・修復・更新は、エンジンの中ですでに実計算されている**。1.9Dでは、そこに手を入れず、個体と系統の長期生存を**測る**仕組みを足した。

## すでに計算されているもの（Stage 1.2〜1.9Cのエンジン）
| 項目 | 実装（`engine19.js`） |
|---|---|
| 個体ID・連続生存期間 | `id`、`age`。細胞が入れ替わっても `age` は続く（個体として連続） |
| 老化 | 固有の損傷が、代謝活動の積算（`internal`、「rateOfLiving」仮定A2）に応じて増える。`sen = 0.012 × (1 + clock/25) × ageing` |
| 損傷の蓄積と死亡 | `damage` が増え、死亡のハザードは `0.3 × damage²` ＋ 事故 ＋ 飢餓 |
| 修復 | `repairRate` 形質×行動（修復行動は2.5倍、休眠は0.5倍）。損傷を `0.15 × fix` 減らす。費用あり（`0.10 × fix`） |
| 身体更新（細胞の入れ替え） | `replaceRatio` で修復の一部を更新に回す。損傷を `0.35 × rep × eff` 減らす。**更新を重ねるほど効きが落ちる**（`eff = 1/(1+P/3)`）、元の細胞の割合 `O` が減る、記憶は元の細胞にしか残らない（仮定A1） |
| 低代謝・休眠 | `metabolism`、`dormancyDepth`。休眠中は消費が小さく、損傷も半分。目覚めに時間がかかる |
| 資源配分 | 消費は、基礎・記憶・修復・狩り・切替・順応・貯蔵に分かれる（`spentBy`）。繁殖には `OFFSPRING_COST` を払う。配分は遺伝形質（修復率、繁殖力、休眠など）と行動で決まり、固定ではない |
| 免疫・病原体 | `immune` 形質、病原体、感染、抗原ごとの免疫記憶（維持コストあり） |
| 学習・記憶 | `memoryLearn`、`memoryUpkeep`、`M`（元の細胞にある分） |
| 順応 | 一定間隔で発達（再順応）。獲得形質は子に伝わらない |

## 足りないもの（1.9Dでは実装しない・できない）
- **癌化・異常細胞・細胞系統どうしの競争**（細胞レベルの計算）：現在の個体は1つの `O`（元の細胞の割合）と `damage` で表している。細胞系統の計算は後続へ。
- **体細胞のゲノム変化**（個体内のゲノム変化と、生殖系列の遺伝的進化の区別）：現在は生殖系列の変異のみ。体細胞変化は未実装。
- **成長・体サイズ**と、サイズに伴う制約（強度・物質輸送・熱放散・重力）。
- **変態**、再生による身体の再構築、複数領域にまたがる個体、融合・分離・共生。
- 免疫が癌を抑える、自己免疫などの副作用。免疫は病原体への防御としてのみ計算している。
- 宇宙・放射線・真空での休眠と活動の区別。温度・圧力・酸素・水分・重力そのものの計算。
- 社会性・言語・文化・ミーム。

## 1.9Dで足したもの（モデルは変えず、観察と判定を足す）
- **エンジンの集計**（計算には影響しない。1.7とビット単位で一致）：年齢別の危険にさらされた回数と死亡数（老化の測定）、損傷の流入と除去（修復の実効）、系統ごとの消費、休眠の開始・目覚め・休眠中の死亡、個体の詳細（元の細胞の割合、更新量、活動と休眠など）。
- **固定終了の撤廃**：ライブ実行の上限を外し、アリーナが空でも、背景から戻れるよう動き続ける（`continueWhenEmpty`）。
- **ゲーム層**：個体の記録（最長）、α〜Ωのランク判定、節目での停止、重要な出来事までの早送り。

## ランク判定の設計方針
- 「能力の合計」や「知能の高さ」ではなく、**個体の自律的な生存**に基づく。
- 連続生存期間（記録）と、6つの能力軸（老化への抵抗、修復、資源効率・低代謝、活動できる環境の広さ、休眠からの回復、競争下での持続）から。どの軸で満たすかは問わず、「何個の軸がどの段階か」で決める（複数の経路）。
- 採点しないもの：外部集団・技術への非依存（現行エンジンでは全個体が自立していて区別できない）、温度・圧力の適応範囲（地図の範囲はダミー）、4領域の外の環境。
- Ωは判定しない（必要な能力の一部が未実装）。判定できる最高はθ（暫定）。
- 判定は観察のみで、選択・繁殖・資源配分には一切入らない（`test19d.js` で確認）。

## 閾値について（正直な記録）
閾値は、初期の標準型・低代謝型などの実測値を見て、「最初はα、低代謝や休眠などの経路でγ前後に届く」ように置いた。**設計上の選択で、生物学的な測定値ではない**。また、時間尺度が未校正なので、ステップは年とは対応づけていない。
