# 単一種独占の診断と、多種共存の検証（Stage 1.9C、Private開発用）

探索的な調査であり、事前登録した仮説検定ではない。スクリプト：`diagnose.js`、`coexistence_study.js`。結果は `study_*.json` と `diag_*.json`。

## 1. 原因の調査（Stage 1.9B相当の設定、3系統・100個体・12シード・4000ステップ）

| 条件 | 最初の1系統が消えるまで（中央値） | 1系統だけになるまで（中央値） | 4000ステップまでに1系統だけ | 3系統とも残った |
|---|---|---|---|---|
| 標準型・狩猟型・頑丈型（領域あり） | 125 | 1675 | 11/12 | 0/12 |
| 同（領域なし） | 150 | 975 | 9/12 | 0/12 |
| **同一の遺伝子の3系統**（領域あり） | 400 | 1075 | 9/12 | 0/12 |
| 同一の遺伝子の3系統（領域なし） | 550 | 1375 | 10/12 | 0/12 |

読み取り：
1. **遺伝子が全く同じでも、約千ステップで1系統になる。** 全系統が同じ餌を取り合い、系統どうしを安定させる仕組みがない。世代時間は約20ステップなので、千ステップは約50世代で、個体数が数百の集団では偶然の増減だけで1系統に決まる。
2. **本当の適応度の差が加わると、さらに速い。** 頑丈型は追加の遺伝子とコストがあり、約125ステップで最初に消える。
3. **領域（4つの区画）の導入は、共存を助けなかった。** どの系統も同じ餌・同じ領域を使うため、領域が棲み分けにならない。

## 2. 対策の検討：餌の資源分割（棲み分け）

植物の餌を3種に分け、系統ごとに配分を持たせた。配分が違えば、同じ種類の競争相手より、自分の仲間のほうが餌を取り合う関係になる（種内競争＞種間競争）。

| 条件（12シード・4000ステップ） | 結果 |
|---|---|
| 同一の遺伝子・**別々の餌**（[1,0,0],[0,1,0],[0,0,1]） | **12/12で3系統とも残った** |
| 同一の遺伝子・**同じ配分**（対照） | 11/12で1系統だけ（資源分割を使わない場合とほぼ同じ） |
| 標準型・狩猟型・頑丈型・配分が重なる・効率差なし | 12/12で1系統だけ（標準型が万能に食べ、勝つ） |
| 同・専門化の効率 0.5 | 2/12で2系統以上 |
| 同・専門化の効率 1.0 | 4/12で2系統以上 |
| 同・専門化の効率 1.5 | **11/12で2系統以上** |

→ 資源分割そのものが共存を生む（上2行の対照）。ただし、配分が重なる現実的な組み合わせでは、万能型が有利になりすぎるため、「専門化したほうが自分の餌をよく消化できる」効率差（0〜1.5）が要る。**1.5を採用した。これは設計上の選択で、測定値ではない。**

## 3. ゲームでの検証（`coexistence_study.js`、標準型＋種から決まる競争相手2種、衝突シナリオ、連続自動）

| 設定 | 4000ステップで2系統以上（個体5以上） | 3系統以上 | 1系統だけになった試行 | 局所絶滅（平均） | 再侵入のあった試行 |
|---|---|---|---|---|---|
| 1.9B（20シード） | 3/20 | 0/20 | 19/20 | 0 | 0 |
| 1.9C 資源分割のみ・背景なし（20シード） | 20/20 | 1/20 | 0/20 | 9.2 | 0 |
| 1.9C 全部（資源分割＋背景からの移入・再侵入）（20シード） | 19/20 | 6/20 | 1/20 | 13.7 | 9/20 |
| 1.9C 全部・12000ステップ（12シード） | 12/12 | 4/12 | 1/12（約7000ステップ） | 33.3 | 8/12 |

読み取り：
- 資源分割が主因（1.9Bの3/20→20/20）。背景からの移入と再侵入は、3系統以上の共存を増やす（1/20→6/20）。
- **共存は保証していない。** 1系統だけになる試行、局所絶滅（領域ごとの消滅）、系統の絶滅が実際に起きている。
- 「一度も1系統にならない」試行が多いのは、背景からの移入が絶えた系統を何度も補う（救済効果）ためでもある。背景なしの行と比べて見ること。

## 4. 初期型ごとの残りやすさ（プレイヤーの型として、8シード・4000ステップ、自分の型が個体5以上で残った回数）
- 第1案（標準型を均等な万能型にした配分）：標準型 1/8、低代謝型 7/8、多産型 6/8、狩猟型 5/8、頑丈型 4/8。
- 第2案A：標準型 7/8、低代謝型 4/8、多産型 6/8、狩猟型 8/8、頑丈型 0/8。
- **採用（第2案B）：標準型 7/8、低代謝型 4/8、多産型 7/8、狩猟型 8/8、頑丈型 3/8。**
- 配分の見直しは、標準型（既定の型）がほぼ消えるのを見たあとに行った（正直な記録）。見直し後は調整していない。型ごとの差は遺伝子とコストによるもので、そのまま報告する。**頑丈型は残りにくい。** プレイヤー系統が少数・絶滅であることは、失敗とは扱わない。

## 5. 未解決・延期
- 種分化・交雑は未実装（無根拠に新種を作らないため、生殖隔離のモデルが先に要る）。
- 系統どうしの捕食は未実装（被食者は背景の機能群として計算）。
