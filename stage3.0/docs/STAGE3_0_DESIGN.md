# Stage 3.0 設計メモ（非公開）

## 区分
- 実計算：個体の生死（箱の外の損傷）、気候シフトによる環境の柱の移動、大災厄の資源・気温・病原体・被害への作用、予告の節目、可変時間の跳躍。
- 統計的近似：跳躍中の世界モデル（個体は進めない）、地球外の一時的生存（簡易輸送モデル）。
- ゲーム上の仮定：温度×圧力の柱の形、形質→箱の式、災厄の種類・確率・規模、緩衝スケジュール、予告の観測モデル、月の危機（作者独自の仮説。太陽光度の上昇は科学的事実として別扱い）。
- 未実装：宇宙での自律的生存（null。計算済みと表示しない）、宇宙の環境・生存計算、箱中心の進化。
- ダミー：なし（表示専用の適応範囲は持たない）。

## 後から調整したパラメータ
長寿命型の定着性が低かったため、ペナルティ緩和ではなく「飢饉」環境を追加（優遇補正なし）。文明の低技術循環を抑える stockStressByTech / lowTechSlack（長期モードのみ。旧セーブは不変）。

## テスト専用の近道
cfg.testStartYears（歴史の途中から開始）、cfg.testHooks（killEarth, addOffworld）、engine live.clear()。通常のゲームでは使われない。

## 既知の限界
- 跳躍中は進化・成長なし。未計算期間は timeLedger に「省略」と記録。
- 30億年代の災厄は常に回復不能。
- 長寿命の初期生物は既定条件では多くが死ぬ。
- α–θ は暫定。Ωは判定しない。
