# Stage 4.0 設計記録（非公開）

依存：PR #12（Stage 3.1, `dev/stage3.1`）の上に積んだ別Draft PR。#11/#12 の状態は変えていない。旧セーブ（v5〜v8）は従来の経路のまま同じ結果に再生される（`cfg.stage===4` の世界だけが新しい経路を通る。保存は v9）。

## 区分
- **史実（外部条件として使う）**：酸素の増加（大酸化）、オゾン層、陸上・空の食べ物の増加、氷河時代・スノーボールアース、オルドビス紀末・デボン紀後期・ペルム紀末・三畳紀末・K–Pg の絶滅、カンブリア紀・真核生物・多細胞・恐竜・哺乳類・人類の「史実の目印」。年代は中心的な推定値。ゲームの系統の進化結果は固定しない（真核生物や多細胞化は目印で、ゲームの系統がそうなるとは限らない）。
- **ゲーム上の仮定**：開始は約38億年前（生命の起源は約42億〜35億年前と幅がある）。気候曲線は粗い読み（暗い若い太陽は温室効果で補われたとする）。絶滅の規模、陸・空の食べ物の増え方、酸素が代謝を制約する式、初期の8系統の設定、人類文明を約1.2万年前の農耕から始め、現代の状態（技術段階6.2）を記録として置くこと。現代まで人類文明は偶然で崩壊しない（`protect`）。現代以前に他の文明は起きない。
- **作品固有の抽象**：コドン（物理長・展開長・機能情報・圧縮率・冗長性）。実際のDNAではない。
- **計算していないもの**：宇宙での自律生存、他種への依存関係（環境支配力）、箱の中心の進化。

## 時間と近似進化
1ステップ=30日。跳躍中は世界のモデルだけを進める（Stage 2.0 からの方針）。Stage 4.0 では、跳躍のあとに実際の世代の代わりとして最大240ステップを、突然変異の供給を2倍にして計算する（近似）。台帳（`timeLedger().approximateEvolution`）にシミュレーションしたステップとは別に数え、省略した世代は進化として数えない。ブラウザを閉じていた間は何も進めない（実際に計算していない期間の出来事は作らない）。復帰時に通知する。

## 初期の8系統と、外の海
原始の海の8系統（好熱・速増・休眠・修復・漂流・捕食・防御・汎用）を全部見る。主注目系統はいつでも変えられる。アリーナの外の「広い海」の背景集団が、各系統の祖先型を送り続ける（Stage 1.9C からの背景生態系の仕組み）。これがないと、競争排除で数十ステップのうちに単一系統になった（測定）。ニッチは3つの餌の分け方でずらした。獲物は動物が現れるまでほぼなし（`prey`：約5.4億年前から）。

## 円盤
扇＝場所（水・地中・空・陸）。扇の幅＝その場所にある環境支配力（個体数ではない）の割合（最小10%）。扇の中の角度＝温度（時計回りが高温）。半径＝圧力（中心＝高圧、外周＝真空に近い低圧、対数）。陸だけ半径＝生活の層（中心＝環境に縛られる、外＝環境を変える文明）。領域の色は、各系統の実際の分布（深さ・高さの区画）を、環境支配力の大きさで広げ、競り合って決める。「角度＝温度かつ角度＝場所」は同じ座標にできないので、階層座標を採った（解釈）。色は系統に固定し、近縁・融合の色は混色で出す。円盤が Ω に似た見た目（`omegaShape`）と、系統の Ω 到達（`rank.js`）は別。

## Ω の判定（暫定）
ランクθ／途切れない個体の生存 12,000 ステップ／測れる能力軸がすべて測れる最高段階／文明に頼らない自律／コドンの安定（圧縮35%以下・冗長20%以上・肥大なし）を、2,000 ステップ保ち続けること。円盤の形は使わない。通常のプレイでは到達していない（隠れた優遇なし）。

## コドン
遺伝子の `len`（物理長）と `len0`（展開したときの長さ）。機能情報＝|重み|≥0.15 の効果の数＋調節遺伝子0.5。密度＝機能情報÷物理長。実際の作用：複製の費用が長さに応じて増える（最大 +50%）、老化が進む（最大 +30%）、圧縮された遺伝子は変異が大きく効く（×(1+2×圧縮率)）、同じ働きの控えがある遺伝子は変異が弱く効く（×0.4）、圧縮が進むほど修復が落ちる（−50%まで）。圧縮は突然変異の一種として自然に起こり（隣の遺伝子との統合、短縮、干渉・欠損のリスクあり）、再展開もある。プレイヤーは編集できない。

## 遺産・図鑑・偉業
- 遺産：系統が絶えると遺伝子3個が漂い、生存個体が拾うことがある（失敗あり、4000ステップで消える）。方針は出会う機会に影響する（捕食1.6倍・共存1.3倍・回避0.6倍、共生で融合が1.5倍）。どれが誰に渡るかは選べない。特殊モードは前の世界の遺産を最初から水に漂わせる。
- 図鑑：形態（6軸の組み合わせ）、能力、耐性、仕組み、コドン。実際に3個体以上がもっている／系統の平均が基準を越えたときだけ記録。希少度＝特徴の極端さ（60%）＋その時の少なさ（40%）。
- 偉業：長寿、わずかな個体での生存、大災厄の突破、極限環境での暮らし、希少な進化の定着。人口は偉業ではない。
- 通常モードの記録は図鑑と偉業だけを次の世界へ（生き物は強くならない）。特殊モードは遺産。記録・評価は別に数える（`omega_meta4`）。

## 系統樹
エンジンが記録した出来事（変異・再編成・分離・融合・交換）だけで描く。親の枝は出来事の親（`par`）。表示は最大160、古くて消えた枝は数だけ。中心から外側へ時間。
