## 3. 課題別の結果

### 課題1：貯蔵の統計的支持と実際の競争勝利の食い違い（Stage 1.5のP1）
**原因は、評価項目が「パルス−安定の差」だったこと。** 差は、すべての維持コストで正になる（安定供給側では高貯蔵が負ける速度の方が速いため）。一方、勝敗は別の話。

競争（容量8 対 3、60試行をまとめた勝率。左から維持コスト0／0.001／0.002／0.004）：
| 供給 | 勝率 | 勝率が半分になる維持コスト（線形補間、事後） |
|---|---|---|
| 安定 | 0.52 / 0.05 / 0 / 0 | ほぼ0 |
| パルス20/4 | 0.85 / 0.62 / 0.27 / 0.05 | **約0.0013** |
| パルス40/8 | 0.85 / 0.72 / 0.37 / 0.12 | **約0.0016** |

- Stage 1.5の基準コスト0.004は損益分岐の約2.5〜3倍で、勝率は5〜12%。だから「差は支持、勝敗は負け」になった。
- 貯蔵の利益は実在する。パルス供給で、コストが約0.0013〜0.0016を超えると消える。
- 選択なしの対照では勝率はほぼ半々（コスト0、パルス）。

### 課題1：貯蔵が進化で増えない原因の分離
変異供給（1/16）× 効果量（1/4）× 供給方式 × 観測期間（2000/6000）で、**保有遺伝子割合と実際の容量の両方**を測った（コスト0、選択ありと選択なし）。
- **変異供給が最大のてこ**：貯蔵を向く遺伝子を持つ個体の割合（2000ステップ、安定・選択あり）は 供給1で0.04〜0.07、供給16で0.46〜0.58。効果量を4倍にしても、容量はわずかに増えるだけ（パルス・選択あり、6000ステップで3.65→3.85、独立シードでは3.33→3.36）。
- **保有割合は選択の指標として不適切**：選択なしでも、中立に保有が広がる。供給16では、6000ステップで選択なしの保有割合が0.94〜0.98に飽和する。保有割合のDiDが正でも、「選択された」とは言えない（P1が不成立だった理由の一つ）。
- **容量は動きが小さく、再現しない**：最大でも、パルス・選択ありの平均容量は3.85（容量8には遠い）。P2は一次で正の差（+0.83）だが、独立シードで消えた。
- **観測期間は絶滅に切られる**（事後）：パルス・選択ありの系統は、2000ステップで38/60、4000で19/60、6000で9/60しか生き残らない。選択なしは全部生存。進化が進む前に系統が絶える。6000ステップ時点の生存系統（9試行）の容量は4.08（選択なしは3.28）で、生き残った系統ほど大きいが、サンプルが小さい。
- **結論**：選択は貯蔵を向く遺伝子を増やすが（供給を増やした条件で）、容量の変化は小さく、再現しない。競争では明らかに有利（コスト0）なのに進化が追いつかないのは、供給・効果量・期間に加え、**系統が先に絶滅する**ため。

### 課題2：感染期間・再感染間隔・記憶持続時間（独立パラメータ）
感染期間 {3, 8, 17} × 流行間隔 {6, 12, 24} × 記憶持続（減衰）{0.1, 1}。観測された感染期間は設定どおり。

| 指標 | 最大の機会（3/6/0.1） | 最小の機会（17/24/1） |
|---|---|---|
| 記憶が保持されていた暴露の割合 | **0.63** | 0.04 |
| 記憶が感染を防いだ回数（1試行） | **約2,800** | 約20 |
| 再感染回数（同じ抗原、1試行） | 約12,600 | 約78 |
| 総利益（コスト0）：個体寿命 | +0.59〜+0.66 | +0.07〜+0.15 |
| 純コスト（利益0）：個体寿命 | −0.52〜−0.54 | −0.27〜−0.33 |
| 純効果（通常）：個体寿命 | +0.05〜+0.08（減衰1の同条件では−0.03〜+0.01） | −0.16〜−0.21 |
| 純効果（通常）：個体数 | −16.4〜−16.9 | −7.7〜−8.6 |

- **再利用の機会が増えると、記憶の利益も増える**（個体寿命の総利益が約9倍）。ただしコストも増える（記憶が蓄積するほど維持費がかかる）。
- **個体寿命の純益は、最大の機会でもほぼ0（+0.05〜+0.08）**。感染の重さを10倍にすると、個体寿命の純益は+0.105 [0.080, 0.128]／+0.112 と確かに正になる。ただし**個体数の純効果は負のまま**（−8.3／−5.5）。
- **個体数と個体寿命で結論が割れる**：記憶は個体を少し長生きさせるが、維持コストで個体数が減る。P4（個体数）はFAIL。
- 総利益は、個体数にはほとんど現れない（0.0〜−4）。
- **進化させたとき**（最大の機会、同一抗原）：記憶への投資（遺伝型）は、選択ありで選択なしより低い（−0.035）。記憶コストを取り除いても、選択なしよりわずかに低い（−0.015 [−0.023, −0.007]、事後）。利益を取り除くと、さらに低い（−0.033）。
- **感染が毎回新しい抗原**でも、純効果は同程度（個体数 −14.9）。

### 課題3：短期繁殖 → 資源枯渇・獲物減少 → 絶滅 の因果経路（パルス供給・選択あり）
介入実験（同じ30シード、2つのシード群）：
| 介入 | 絶滅（一次／独立） | 個体数の中央値 | 初期400ステップの出生率 |
|---|---|---|---|
| 基準 | 10/30、11/30 | 70、74 | 0.091 |
| 獲物の避難30% | **0/30、0/30** | 422、414 | 0.099 |
| 繁殖を創始値に固定 | 11/30、7/30 | 71、71 | **0.090（基準と同じ）** |
| 獲物なし | 30/30、30/30（約26ステップ） | 15 | 0.019 |
| 避難＋繁殖固定 | 0/30、0/30 | 410、407 | 0.097 |
| （参考）選択なし | 0/30、0/30 | 122 | 0.081 |

- **獲物の枯渇が絶滅の経路である**ことを支持する：選択を受けた系統は、選択なしより獲物の割合の最小が0.34低く、獲物の割合（初期）も0.12低い。獲物の避難で絶滅は消える。獲物を完全になくすと全滅するので、パルス供給では獲物が必須の緩衝になっている。
- **繁殖力の遺伝型は、この経路に関与していない**：固定しても、出生率が変わらず（0.090対0.091）、絶滅も変わらない。選択による出生率の増加（+0.010）は、繁殖力のゲノム値ではなく、狩猟などによるエネルギー収支から来ている。したがってP6のFAILは、「早い繁殖は無関係」の証明にはならない（固定が何も動かさなかった）。
- **観察的な連鎖**（事後、60試行をまとめた）：初期の出生率が高いほど、初期の獲物の割合が低い（ρ=−0.77 [−0.85, −0.63]）。初期の獲物の割合が高いほど、系統が長く続く（ρ=+0.25 [0.01, 0.46]）。初期の出生率が高いほど、系統が短い（ρ=−0.27 [−0.49, −0.002]）。狩猟時間と獲物の割合は負の相関（ρ=−0.41）。**相関であり、因果の証明ではない。**

## 5. 解釈上の留保・限界
1. **P5の獲物の避難は、獲物の保護であると同時に食料の補助でもある。** 毎ステップ獲物が下限まで補充されるため、個体数が約6倍になった（70→420、事後）。絶滅が消えたのは「枯渇経路の遮断」だけでなく「食料の追加」の効果も含む。経路の特定には、補助を伴わない介入（出生数の上限など）が必要。
2. **P6の繁殖固定は、実質的に何も動かさなかった**（出生率が同じ）。早い繁殖そのものの因果は、**未検証**。
3. 貯蔵の進化の評価では、保有割合は中立な広がりで飽和し、容量は変化が小さく再現しない。評価項目の設計を見直す必要がある（次の段階の候補）。
4. 記憶の「個体寿命の純益」が正になるのは、感染の重さを10倍にした探索的な条件だけ（記憶コストを下げずに）。個体数では負のまま。
5. 全パラメータは手調整の仮定値。新器官や真の創発は立証しておらず、主張しない。
6. **事後分析**（`posthoc16.js`）は、結果を見てから設計した。損益分岐、保有割合と容量の食い違い、生存の推移、経路の相関、避難の補助効果。結論には使っていない。
7. 評価した個体寿命は、絶滅した試行も含む全死亡の平均。系統存続期間は2000ステップ（E1は6000）で打ち切られている。

## 6. 次の段階へのゲート
Stage 2には進まない。記憶・長寿・貯蔵の自然進化は、確認的な基準を満たしていない。

**次の候補**（科学的前提に関わるため、独立監査の後に）：
1. 因果経路：食料の補助を伴わない介入（出生数の上限、獲物の初期個体の保護など）で、早い繁殖の因果を検証する。
2. 貯蔵の進化：保有割合ではなく、競争で測る適応度勾配（遺伝子を入れた系統の勝率）を評価項目にし、系統が絶滅する前に進化できるよう、パルスの強さを弱めた条件で期間を延ばす。
3. 記憶：維持コストの構造（学習機構を持つだけでかかる分）が妥当かを、生物学的根拠から先に決めて事前登録する。
